# Food & Future

Food & Future (ent. Viral Vegans) on vastuullisen ruoan riippumaton
asiantuntija. Se tuottaa luotettavaa tietoa siitä, miten ruoantuotanto
vaikuttaa ihmisiin, eläimiin ja ympäristöön.
